⏺ Sanitization

  When RDKit reads a molecule from an SDF file, the raw file is just a list of
  atoms and bonds — no chemical intelligence. Sanitization is RDKit's
  post-processing pass that derives chemical properties from that raw
  connectivity:

  1. Ring detection — which atoms are in rings
  2. Aromaticity perception — mark bonds/atoms as aromatic (e.g. benzene)
  3. Hybridization assignment — SP, SP2, SP3 based on connectivity
  4. Valence checking — does each atom have a chemically legal number of bonds?

  Your features (GetIsAromatic, IsInRing, GetHybridization) come from steps 1–3.
   Step 4 is what was crashing.

  ---
  Valence Bookkeeping

  Valence is the number of bonds an atom can form. Carbon normally allows
  exactly 4. The error:

  Explicit valence for atom # 28 C, 4, is greater than permitted

  means RDKit counted more than 4 bonds on that carbon atom. This happens
  because PDBBind SDF files were written by software that uses extended valence 
  models (e.g. Schrodinger, OpenBabel) that allow temporary over-valent
  representations during protonation state assignment or tautomer enumeration.
  The file is geometrically valid (the 3D coords are fine), but it violates
  RDKit's strict chemistry rules.

  RDKit's sanitization step 4 sees this carbon, says "illegal", and refuses to
  return the molecule at all — giving you None.

  ---
  The 2D/3D Warning

  SDF files have a header line that declares dimensionality (2D or 3D). Some
  PDBBind entries were originally processed from 2D SMILES, got 3D coordinates
  embedded later, but the header was never updated. So the file says 2D but has
  non-zero Z coordinates. RDKit detects the contradiction and auto-fixes it —
  the warning is just it narrating that correction. Completely harmless.

  ---
  Why SANITIZE_ALL ^ SANITIZE_PROPERTIES works

  ^ is XOR — it flips off the SANITIZE_PROPERTIES bit (valence checking) while
  keeping all other bits on. So RDKit still runs ring detection, aromaticity,
  and hybridization — giving your feature extractor everything it needs — but
  never reaches the valence check that would reject the molecule.
